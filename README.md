# SlitterFlow — ทดลองใช้งาน

เปิดเว็บที่ https://fcnc2.github.io/SlitterFlow/ บน GitHub Pages โดยไม่ต้องเชื่อม Microsoft 365 หรือ SharePoint

Operator เลือกชื่อ Shift Manager แทน Team A–D ตรวจเครื่องจักร/Dolly กรอก Condition เลือกใบมีด และกดส่งบันทึก รายการจะอยู่ในสถานะรอตรวจสอบ Shift Manager เห็นรายการรอตรวจทั้งหมดตามพื้นที่ที่ได้รับสิทธิ์ เปิดอ่านผลตรวจและ Condition ทุกข้อ แล้วอนุมัติหรือระบุเหตุผลส่งกลับ Operator โหลดเอกสารที่ส่งกลับด้วย DocNo เพื่อแก้ไขและส่งใหม่ได้ Viewer/Admin กดกรองก่อนอ่านข้อมูลและ Export CSV (รวมสถานะการตรวจสอบ) ได้ Admin เพิ่ม Shift Manager เปลี่ยนชื่อบัญชี กำหนดสิทธิ์ตรวจสอบ และเพิ่มหรือยกเลิก Parameter แยก TH3/TH4 ได้

ข้อมูลรายการ สถานะการตรวจสอบ Parameter และบัญชีทดลองใช้ `localStorage` ในเบราว์เซอร์เครื่องที่เปิดเว็บเท่านั้น ไม่ถูกส่งไปฐานข้อมูลและไม่แชร์ข้ามเครื่อง/เบราว์เซอร์ **การทดลอง Operator → Shift Manager ต้องทำในเบราว์เซอร์เดียวกัน** การล้างข้อมูลเว็บไซต์จะลบข้อมูลทดลอง บัญชีและรหัสผ่านทดลองเก็บอยู่ในเบราว์เซอร์และไม่ใช่ระบบยืนยันตัวตนจริง อย่าใช้กับข้อมูลการผลิตจริงจนกว่าจะมีฐานข้อมูลกลางและระบบบัญชีฝั่งเซิร์ฟเวอร์

โค้ดเชื่อม SharePoint เดิมยังอยู่ใน repository สำหรับการพัฒนาครั้งถัดไป แต่หน้าเว็บทดลองไม่เรียกใช้งาน เส้นทาง build ของ GitHub Actions ใช้ `npm ci` และ `npm run build` จาก `src/main.tsx` เพื่อเผยแพร่เวอร์ชันปัจจุบัน
